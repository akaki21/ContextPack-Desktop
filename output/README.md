# Output folder

Generated files are written here. Start an AI review with Markdown, then provide originals or selected page images only when verification is needed.

- Text summary: provide the main `.md`.
- PDF verification: add the source/OCR PDF.
- Visual verification: add only relevant PNG pages.
- Excel analysis: provide `workbook-info.md`, `formulas.md`, and `values.md`; add the workbook for exact checks.

Full packages include English and Georgian AI handoff files.
