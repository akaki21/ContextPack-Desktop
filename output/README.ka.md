# Output საქაღალდე

აქ იქმნება დამუშავებული ფაილები. სრული პაკეტი შეიცავს `manifest.json`, `quality-report.md`, წყაროს provenance-სა და ორენოვან AI handoff-ს. AI-ს ჯერ ეს მსუბუქი ფაილები მიაწოდე, ხოლო ორიგინალი და საჭირო გვერდების სურათები მხოლოდ გადამოწმებისთვის გამოიყენე.

თუ Codex იმავე კომპიუტერზე მუშაობს, მიუთითე პაკეტის საქაღალდის მისამართი და დავალება. ყველა ფაილის ცალ-ცალკე მიმაგრება საჭირო არაა.

- ტექსტური შეჯამება: მთავარი `.md`.
- PDF-ის შემოწმება: საწყისი/OCR PDF.
- ვიზუალური შემოწმება: მხოლოდ საჭირო PNG გვერდები.
- Excel: `workbook-info.md`, `formulas.md`, `values.md`, `print-layout-report.json`, შემდეგ მხოლოდ საჭირო `sheets-data` ფაილები; ზუსტი შემოწმებისთვის — `workbook-layout`/ორიგინალი, სწრაფი წაკითხვისთვის — `auto-layout`.

Excel-ის ნაგულისხმევი `Both` რეჟიმი ორ PDF/PNG ნაკრებს ინახავს და მეტ ადგილს იკავებს. თუ მხოლოდ ავტორის ბეჭდვის ზუსტი ხედი გჭირდება, აირჩიე `Workbook`.
