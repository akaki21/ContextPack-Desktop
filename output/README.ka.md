# Output საქაღალდე

აქ იქმნება დამუშავებული ფაილები. AI-ს ჯერ Markdown მიაწოდე, ხოლო ორიგინალი და საჭირო გვერდების სურათები მხოლოდ გადამოწმებისთვის გამოიყენე.

- ტექსტური შეჯამება: მთავარი `.md`.
- PDF-ის შემოწმება: საწყისი/OCR PDF.
- ვიზუალური შემოწმება: მხოლოდ საჭირო PNG გვერდები.
- Excel: `workbook-info.md`, `formulas.md`, `values.md`; ზუსტი შემოწმებისთვის — workbook.
