# ContextPack Desktop 2.2.0

ContextPack Desktop 2.2.0 is the first beginner-friendly Windows desktop release.

## Highlights

- Bilingual English/Georgian GUI with output-folder selection, progress, cancellation, logs, and AI handoff actions.
- Automatic PDF, scanned PDF, image OCR, Excel, Markdown, and Office-document routing.
- Complete PDF packages with source, Markdown, page text, PNG pages, manifest, and quality report.
- Complete Excel packages with source values, formulas, workbook metadata, preserved print layout, guarded AutoFit view, manifest, and quality report.
- Per-user Windows installer with automatic dependency checks, Start Menu/Desktop shortcuts, repair flow, and uninstall.
- Versioned portable ZIP and SHA-256 checksums.

## Requirements and notes

- Windows 10 or 11 and internet access during first setup.
- Microsoft Excel is optional and used only for Excel visual rendering.
- Processing is local; ContextPack does not upload documents.
- The installer is not code-signed yet, so Windows may show a publisher warning. Verify the SHA-256 checksum before running it.
