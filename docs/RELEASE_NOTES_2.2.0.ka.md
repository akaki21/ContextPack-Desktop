# ContextPack Desktop 2.2.0

ContextPack Desktop 2.2.0 არის პირველი Windows desktop გამოშვება, რომელიც დამწყებისთვისაც მარტივად გამოსაყენებელია.

## მთავარი სიახლეები

- ორენოვანი ქართული/ინგლისური GUI: output საქაღალდის არჩევა, პროგრესი, გაუქმება, ლოგები და AI handoff მოქმედებები.
- PDF-ის, დასკანერებული PDF-ის, სურათის OCR-ის, Excel-ის, Markdown-ისა და Office დოკუმენტების ავტომატური ამოცნობა.
- სრული PDF პაკეტი: ორიგინალი, Markdown, გვერდობრივი ტექსტი, PNG გვერდები, manifest და quality report.
- სრული Excel პაკეტი: ორიგინალი, მნიშვნელობები, ფორმულები, workbook metadata, ავტორის print layout, დაცული AutoFit ხედი, manifest და quality report.
- ერთ მომხმარებელზე დასაყენებელი Windows installer: კომპონენტების ავტომატური შემოწმება, Start Menu/Desktop shortcut-ები, repair და uninstall.
- ვერსირებული portable ZIP და SHA-256 checksum-ები.

## მოთხოვნები და შენიშვნები

- Windows 10 ან 11 და ინტერნეტი პირველი გამართვისას.
- Microsoft Excel სავალდებულო არაა და მხოლოდ Excel-ის ვიზუალური რენდერისთვის გამოიყენება.
- დამუშავება ლოკალურია; ContextPack დოკუმენტებს არსად ტვირთავს.
- installer ჯერ code-signed არაა, ამიტომ Windows-მა შეიძლება უცნობი გამომცემლის გაფრთხილება აჩვენოს. გაშვებამდე გადაამოწმე SHA-256 checksum.
