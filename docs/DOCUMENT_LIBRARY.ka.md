# დოკუმენტების ბიბლიოთეკისთვის გამოყენება

ContextPack 2.3 ამზადებს ადგილობრივ ტექსტს, ცხრილებსა და გვერდებს შემდგომი შემოწმების, განმარტებებისა და ძიებისთვის. ნორმის მოქმედებას, საქართველოში გამოყენებადობას ან რიცხვების სისწორეს პროგრამა ავტომატურად არ ადასტურებს.

განახლების შემდეგ ერთხელ გაუშვი `setup.ps1`, შემდეგ გახსენი `Start-ContextPack-GUI.cmd`. აირჩიე PDF, HTML ან სურათი და დააჭირე **OCR და PDF/HTML შენახვის პარამეტრები…**.

| პარამეტრი | დანიშნულება |
|---|---|
| OCR ენები | რუსული, ქართული, ინგლისური ან მათი კომბინაცია. ინტერფეისის ენა ამ არჩევანს არ ცვლის. |
| PDF სურათები | ყველა ზღვრამდე, მხოლოდ სუსტი ტექსტის გვერდები, ან სურათების გარეშე. |
| სურათების მაქსიმუმი | ნაგულისხმევად 100; 0 ნიშნავს შეუზღუდავს. ტექსტი ყველა გვერდიდან ამოიღება. |
| დედნის ასლი | დამოუკიდებელი PDF/HTML პაკეტი დედნის ასლით. |
| დედნის მისამართი | ინახება მისამართი და ჰეში. დედანი თავის ადგილზე უნდა დარჩეს. |
| თავიდან დამუშავება | არსებული უცვლელი PDF/HTML შედეგის ხელახალ გამოყენებას გამოტოვებს. |

```powershell
.\contextpack.ps1 '.\input\norm.pdf' -Mode Auto -OcrLanguages rus+eng -PdfRenderMode Sparse -MaxRenderPages 30 -SourcePolicy Reference -OutputDirectory 'D:\Library\processed'
.\contextpack.ps1 '.\input\norm.html' -SourcePolicy Reference -OutputDirectory 'D:\Library\processed'
```

`Full` ქმნის პაკეტს PDF-ის OCR-ის გარეშე; `Ocr` ითხოვს ამოცნობას; `Fast` მხოლოდ ძველ სწრაფ Markdown კონვერტაციას აკეთებს. `Fast` არ ინახავს HTML-ის სტრუქტურულ ცხრილებს და არ იყენებს პაკეტის განმეორებით გამოყენებას. ახალი მითითებით შენახვა და ხელახალი გამოყენება ეხება PDF/HTML პაკეტებს.

შედეგში ჯერ `quality-report.md` წაიკითხე. HTML-ის `tables.json` ინახავს უჯრის პოზიციას, გაერთიანებებს, სათაურებსა და ახლომდებარე ტექსტს. რიცხვები სტრიქონებად რჩება; ათწილადი მძიმე და განმეორების ნიშნები არ გადაიანგარიშება. გამოყენებამდე დედანს შეადარე. თუ Markdown-ის წამკითხველი HTML ცხრილებს ვერ აჩვენებს, გამოიყენე JSON და დედანი.

PDF-ის მთავარი Markdown და `page-text.md` გვერდებადაა დაყოფილი. `pdf-metrics.json` ასახავს ამოღებულ ტექსტს, სუსტ გვერდებსა და დამატებით OCR-ს. ეს ტექსტი ჯერ არ არის სანდო რიცხვითი ცხრილი.

თუ პირველი გზით ტექსტი სუსტი ან დაზიანებულია, გვერდი სურათიდან ამოიცნობა მაქსიმუმ 300 DPI-ზე. `ocr-pages/` ინახავს ტექსტსა და სიტყვების კოორდინატებს. სიზუსტის მაჩვენებელი დიაგნოსტიკაა; რიცხვები, ერთეულები და ნიშნები დედანთან მოწმდება. ამ გზით აღდგენილი სიტყვები OCR PDF-ში არ ემატება — ისინი Markdown/TSV-შია. OCR-ისთვის დროებითი სურათი შეიძლება შეიქმნას შენახული სურათების გამორთვის შემთხვევაშიც.

ინტერნეტიდან ან დოკუმენტის საქაღალდის გარედან HTML სურათები არ ჩამოიტვირთება/გადმოიტანება. გამოტოვებები აღირიცხება `assets.json`-სა და გაფრთხილებებში.

თუ დედანი, პარამეტრები, კოდი, დამოკიდებულებები და შედეგის ყველა ფაილი უცვლელია, PDF/HTML პაკეტი თავიდან აღარ დამუშავდება. მოდელის ან HTML-ის ადგილობრივი სურათის ცვლილებაც მოწმდება. თუ შედეგში ვინმემ ფაილი დაამატა ან შეცვალა, გადამუშავება ძველ პაკეტს `.previous-<id>` სახელით ინახავს. დამოწმებული განმარტებები და პროექტის ჩანაწერები გენერირებული პაკეტის გარეთ შეინახე.

დედანი უცვლელია. თუ დამუშავებისას წყარო შეიცვალა, ახალი პაკეტი არ გამოქვეყნდება. `Reference` ზოგავს ადგილს, მაგრამ დედნის შემდგომი გადაადგილება მის ბმულს დააზიანებს.

ტექნიკური ტესტები და გარემოს ცალკე სამუშაო ასლში გამოყენება აღწერილია [ინგლისურ ინსტრუქციაში](DOCUMENT_LIBRARY.md).
