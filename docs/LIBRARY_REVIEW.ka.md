# ეკონომიური შენახვა და გადამოწმება — 2.3.1

ბიბლიოთეკის PDF-ისთვის გამოიყენე `-PdfRenderMode None -SourcePolicy Reference -OcrPdfPolicy Temporary`. OCR-ის PDF და სამუშაო რასტრები დროებით იქმნება არჩეული შედეგის დისკზე; ტექსტის ამოღების შემდეგ პაკეტში აღარ რჩება. `Keep` და `Copy` ძველ პორტატულ არჩევანს ინარჩუნებს. GUI-ის დამატებით პარამეტრებში დაემატა „PDF-ის OCR ასლი“.

`None` მხოლოდ PDF-ის PNG ექსპორტს მართავს. Excel-ის სამუშაო წიგნის ასლი, PDF/PNG ხედები და HTML-ის თანმხლები ილუსტრაციები სხვა გზით იქმნება. Fast რეჟიმს პაკეტის ახალი ჟურნალი არ აქვს. ძველი `ocr-and-convert.ps1` OCR PDF-ს კვლავ ტოვებს; ეკონომიისთვის გამოიყენე `contextpack.ps1`.

ღრმად ჩაშენებული Windows ბილიკებისთვის გაშვებამდე მიუთითე `$env:CONTEXTPACK_TEMP = 'E:\Engineering-Assistant\99_Temp\ocr'`. ეს მოკლე დროებით ბილიკს აძლევს OCRmyPDF-სა და Tesseract-ს; იშლება მხოლოდ კონკრეტული დავალების დროებითი ქვესაქაღალდე. პარამეტრის გარეშე დროებითი შედეგები build-შია. GUI-იც მემკვიდრეობით იღებს ამ გარემოს ცვლადს. სხვა ხელსაწყოებისთვის `TEMP`/`TMP`-ც E: დისკზე მიუთითე.

პილოტში კონკრეტული PDF გვერდები CLI-ით აირჩიე: `-PdfPages '1-3,9,15'`. დედნის ნომრები შენარჩუნდება; `extracted_pages` ზუსტ დაფარვას აჩვენებს. გამოტოვებული პარამეტრი ყველა გვერდს ნიშნავს. არასწორი დიაპაზონი დასრულებულ პაკეტს არ ქმნის.

`review.json` მიუთითებს პაკეტის გვერდით არსებულ `.contextpack-reviews/<წყაროს SHA-256>/` საქაღალდეზე. მასში ინახება უცვლელი საწყისი ტექსტის/ცხრილების/TSV-ის ჰეშირებული ვერსიები, პრაქტიკული CHECKLIST და მოვლენების მდგრადი `events.jsonl` ჟურნალი. გვერდების სურათები და PDF დედანი აქ არ დუბლირდება. `input-page-text.md` ინახავს ტექსტს დამატებით OCR-მდე. შესწორებები ცალკე ჩანაწერებია; საწყის OCR-ს არ გადაწერს.

სტატუსები: `extracted` — ამოღებული; `needs_review` — გადასამოწმებელი; `source_verified` — მითითებულ ადგილზე დედანთან შემოწმებული. უცნობი რიცხვი ვარაუდით არ შეასწორო. შეადარე ათწილადი გამყოფი, მინუსი, შედარების ნიშანი, ხარისხი/ინდექსი, ერთეული და ცხრილის სათაურებთან მიბმა. ნახაზის შინაარსი ვიზუალურად შეამოწმე. TSV და confidence მხოლოდ დამატებითი OCR-ის გვერდებს მოიცავს; სხვა გვერდის გადამოწმებას არ ნიშნავს.

ჟურნალის ჩანაწერს სჭირდება წყაროს ჰეში/რედაქცია, გვერდი/პუნქტი/ცხრილი/უჯრა ან ზონა კოორდინატთა სისტემით, საწყისი და შესწორებული ტექსტი, სტატუსი, შემმოწმებელი, მეთოდი და საწყისი ამოღების ჰეში. გაურკვეველი შესწორება იყოს `null`. ხელახალი კონვერტაცია და `-Force` ჟურნალს ინარჩუნებს. შეცვლილი წყარო ცალკე ჟურნალს იღებს; ძველი შესწორება ახალ რედაქციაზე ავტომატურად არ ვრცელდება.

პაკეტის გადატანისას მისი გვერდით მდგომი ჟურნალიც გადაიტანე. უცვლელი პაკეტი ხელახლა გამოიყენება, მათ შორის ჟურნალში ახალი სწორი ჩანაწერის დამატების შემდეგ; დაზიანებული ჟურნალი/საწყისი ტექსტი შეცდომით ჩერდება. პროცესის იძულებით გათიშვისას დარჩენილი დროებითი build ან `.writer.lock` ცალკე შესამოწმებელია.

[ზუსტი ველები, CLI და შეზღუდვები](LIBRARY_REVIEW.md). ნორმის მოქმედების სტატუსი და საბოლოო საპროექტო გადაწყვეტილება ამოღების პროგრამით არ დასტურდება.
