# ContextPack Desktop GUI — პირველი გამოყენება

ეს არის ContextPack-ის ლოკალური Windows ინტერფეისი. ფაილები შენს კომპიუტერზე მუშავდება და GUI არსებულ PowerShell/Python ძრავას იყენებს.

## გაშვება

1. გახსენი ContextPack-ის პროექტის საქაღალდე.
2. ორჯერ დააწკაპუნე `Start-ContextPack-GUI.cmd` ფაილზე.
3. თუ გარემო აკლია, ჯერ გაუშვი `setup.ps1`; უკვე გამართულ პროექტში დამატებითი ინსტალაცია საჭირო არაა.

ზედა მარჯვენა კუთხეში ენის გადამრთველი მთელ ინტერფეისს მყისიერად ცვლის ქართულსა და ინგლისურს შორის. ენის შეცვლისას დამუშავების არჩეული რეჟიმი შინაგან მნიშვნელობას ინარჩუნებს.

შეგიძლია ფაილი პირდაპირ `Start-ContextPack-GUI.cmd`-ზეც გადაათრიო — ფანჯარა ამ ფაილით გაიხსნება.

## ძირითადი სამუშაო პროცესი

1. **აირჩიე ფაილი** — PDF, Excel, სურათი ან მხარდაჭერილი Office/მონაცემთა ფაილი.
2. **აირჩიე რეჟიმი** — პირველად დატოვე `ავტომატური — რეკომენდებული`.
3. Excel-ისთვის პირველად დატოვე `ორივე ხედი — რეკომენდებული` და DPI `180`.
4. დააჭირე **დამუშავების დაწყებას** და აირჩიე შენახვის საქაღალდე. ფანჯარა ნაგულისხმევად Desktop-თან ახლოს გაიხსნება.
5. დასრულების შემდეგ გამოიყენე **შედეგის გახსნა** ან **AI დავალების კოპირება**.

არჩეული ადგილი პირდაპირ გამოიყენება: სრული პაკეტი ატომურად იმავე საქაღალდეში იგება და პროექტის `output`-ში დამატებითი ასლი წინასწარ არ იქმნება.

## რეჟიმების მნიშვნელობა

- **ავტომატური** — PDF-ზე თვითონ წყვეტს OCR-ის საჭიროებას; Excel-ზე სრულ პაკეტს ქმნის.
- **სწრაფი** — ქმნის მხოლოდ ტექსტურ შედეგს და ვიზუალურ პაკეტს არ აშენებს.
- **სრული პაკეტი** — ქმნის PDF/Excel-ის სრულ პაკეტს, მაგრამ PDF-ზე OCR-ს იძულებით არ რთავს.
- **OCR** — გამოიყენე სკანირებულ PDF-ზე; სურათებზე OCR ავტომატურად მუშაობს.

Excel-ის ხედები:

- **ორივე ხედი** — ქმნის ავტორის `workbook-layout`-სა და დამხმარე `auto-layout`-ს;
- **Workbook** — უფრო მცირე output, მხოლოდ ავტორის ზუსტი print layout;
- **AutoFit** — მხოლოდ დამხმარე, ერთ გვერდის სიგანეზე მორგებული ხედი.

## Cancel როგორ მუშაობს

Cancel არ კლავს Excel-ს ძალით. ის ქმნის გაუქმების მოთხოვნას და მიმდინარე უსაფრთხო ოპერაციის დასრულებას ელოდება. ამიტომ დიდი Excel/PDF-ის შემთხვევაში რეაქციას შეიძლება მცირე დრო დასჭირდეს. ეს იცავს წყარო ფაილსა და უკვე არსებულ კარგ პაკეტს.

## Environment Check და Setup / Repair

- **Environment Check** არაფერს ცვლის — მხოლოდ Python/MarkItDown/OCR/Excel გარემოს ამოწმებს.
- **Setup / Repair** საჭირო კომპონენტებს ამოწმებს და აყენებს/აახლებს. გამოიყენე მხოლოდ მაშინ, როცა შემოწმება პრობლემას აჩვენებს.

ზედა მარჯვენა კუთხეში `✓` ნიშნავს, რომ კომპონენტი სწრაფი შემოწმებით ხელმისაწვდომია; `!` ნიშნავს, რომ დეტალური Environment Check არის საჭირო.

## AI-სთვის შედეგის მიწოდება

**AI დავალების კოპირება** clipboard-ში წერს პაკეტის მისამართსა და სწორ საწყის ინსტრუქციას. ტექსტი ჩასვი Codex-ში და ბოლოში მიუწერე შენი კონკრეტული მიზანი. ყველა PNG/PDF ფაილის ცალ-ცალკე ატვირთვა საჭირო არაა, როცა Codex ამავე კომპიუტერზე მუშაობს.
