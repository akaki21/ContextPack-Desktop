# მაგალითები

`sample.csv` არის პატარა, არაკონფიდენციალური input ფაილი ახალი ContextPack ინსტალაციის შესამოწმებლად.

```powershell
.\contextpack.ps1 ".\examples\sample.csv"
```

შედეგი შეიქმნება `output\sample.md` მისამართზე. შეადარე `demo-output\sample.md` ფაილს — ის შექმნილია ContextPack 2.2.0-ით და რეპოზიტორში ინახება როგორც მოსალოდნელი შედეგი.

GUI-ის სამუშაო პროცესისთვის გამოიყენე [60-წამიანი დემო](../docs/QUICK_DEMO.ka.md).
