# Examples

`sample.csv` is a tiny, non-sensitive input for checking a new ContextPack installation.

```powershell
.\contextpack.ps1 ".\examples\sample.csv"
```

The result is created at `output\sample.md`. Compare it with `demo-output\sample.md`, which was generated by ContextPack 2.2.0 and is checked in as the expected result.

For the GUI workflow, follow the [60-second demo](../docs/QUICK_DEMO.md).
